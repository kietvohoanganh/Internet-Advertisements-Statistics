# Data

Run `make download` from the project root to obtain the public [UCI Internet Advertisements dataset](https://doi.org/10.24432/C5V011), created by Nicholas Kushmerick and licensed CC BY 4.0.

`raw/` stores the unchanged source files. `processed/` is regenerated by `make run`. Both directories are ignored except their `.gitkeep` placeholders. Source checksums, duplicate/conflict counts and observed missingness are computed during import. Do not commit either local dataset directory.
